# Research_repo
Репозиторий содержит материалы курсовой работы, посвящённой исследованию факторов, влияющих на уровень заработной платы в различных секторах российского рынка труда.

## Содержание

- `getting_data.ipynb` — сбор данных о вакансиях с использованием API HeadHunter;
- `EDA_regression_analysis.ipynb` — предварительная обработка данных, разведочный анализ и построение регрессионных моделей.

## Используемые технологии

- Python
- Jupyter Notebook
- Pandas
- NumPy
- SciPy
- Matplotlib
- Statsmodels
- Scikit-learn
- Stargazer
- Folium
- Requests
- HeadHunter API

## Методы анализа

- Разведочный анализ данных (EDA)
- KModes
- Линейная регрессия
- Регрессия с эффектами взаимодействия
- Регуляризованные модели (Lasso)
- Decision Tree
- Random Forest
- Gradient Boosting
